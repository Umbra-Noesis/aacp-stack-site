The Problem

Rules the AI follows while it works

AACP sets rules the AI must follow while it works: report only what its tools actually returned, never invent missing data, and report failures plainly.

AACP is used inside EVE Systems, the locally hosted software platform that EVAA™, Umbra-Noesis's in-house AI, runs on. It is internal: Umbra-Noesis software and components are not currently offered under a public license.
